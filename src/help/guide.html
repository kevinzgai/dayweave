DAYWEAVE · 使用手册

把时间和念头，织成每一天

这是一份完整操作说明：从第一次打开应用，到把「捕捉 → 排程 → 专注 → 复盘」跑成日常习惯。全部功能均可离线使用，数据只存在你自己的电脑上。

版本 1.3.7适用平台 Windows离线 · 无需登录

关于本手册

手册按「入门 → 模块 → 进阶」三段组织。第一次使用，建议先读快速开始和每日使用流程，十分钟就能把主流程跑通；之后遇到具体功能，再来查对应模块章节。

左侧目录支持搜索。在搜索框输入关键词（例如「复盘」「打卡」「备份」），目录会实时过滤；点击任意条目即可跳到对应章节。

快速开始

A安装与启动

  1. 安装：双击 织日_1.3.7_x64_zh-CN.msi，按提示完成安装；或直接运行免安装版 dayweave.exe。
  2. 打开：从开始菜单或桌面图标启动，窗口标题为「织日 · DayWeave」。
  3. 先别急着录入：首次启动自带一组演示数据，方便你熟悉界面；确认要正式开始后，去「设置中心 → 重置全部数据」清空即可。
系统要求：Windows 10 / 11。个别精简版系统若提示缺少 WebView2 运行时，安装微软官方 WebView2 Runtime 后即可正常启动（装一次，之后不再需要）。

B三分钟跑通主流程

  1. 打开 闪念，把脑子里盘旋的三件事敲进去，回车捕捉。
  2. 逐条点 转任务，把它们变成正式任务。
  3. 打开 任务管理，给今天必须推进的 2–3 件任务勾上 ★ 今日要事，并设置四象限。
  4. 去 日程 / 时间块，为这几件事预留具体时段。
  5. 到 专注计时，选 25 分钟，开干。
  6. 睡前打开 时间复盘，回答四个问题并保存。
捕捉→转任务→定要事→排时间块→专注执行→复盘沉淀

界面结构

整个应用由三块组成，固定不变：

▤左侧导航栏

深色区域，15 个功能入口分四组：工作台、效率、知识、复盘。底部是当日励志语。闪念有待处理条目时，入口右侧会显示数字角标。

▥顶部信息栏

显示当前模块名称、日期与星期、今日任务完成度，最右侧是昵称头像。窗口可自由缩放，内容区会自适应。

▦主内容区

各模块的具体内容。面板之间留白分隔，不使用重边框；所有改动即时生效并自动保存，没有「保存整个页面」的概念——只有表单类操作（复盘、设置里的昵称）需要点各自的保存按钮。

+新增记录：一律用弹窗

任务、时间块、项目、目标、习惯、知识素材、经验、工作成果的「新增」都在弹窗里完成，页面本身不会被表单撑开或挤动。三个通用操作：

  • 弹窗底部固定「取消 / 保存」两个按钮，样式与应用全局一致；点「取消」放弃本次编辑，未保存的内容不会写入。
  • 长表单在弹窗内部滚动，保存 / 取消按钮始终在底部，不会顶出视野。
  • 窗口宽度小于 900px 时，左侧导航收成抽屉，点左上角菜单按钮展开；弹窗改为从底部滑出的全宽面板，适合触屏操作。
弹窗与确认框采用「显式操作」设计：不依赖 Esc 或点遮罩关闭，必须通过「取消 / 保存 / 删除」等按钮完成，避免误触丢数据。

外观与配色

界面默认复刻参考稿的配色：深藏蓝侧栏 + 暖黄高亮条 + 亮蓝进度，主内容区浅灰底配白色卡片。在这套骨架上另备了 5 套配色方案，随时可换：

方案风格适合场景
藏蓝暖阳深藏蓝侧栏 · 亮蓝 #3B7DF6 · 暖黄 #F2C14E（默认，复刻参考图）白天办公，信息层级最清晰
樱粉晨光深玫瑰侧栏 · 玫瑰粉 #E45C8C · 奶油金偏柔和的个人使用场景
薄荷青竹墨绿侧栏 · 竹青 #16A97F · 沙金长时间盯屏、需要冷静的深度工作
紫罗兰暮光深紫侧栏 · 暮紫 #7B61E8 · 落日金创作、学习，氛围感强
石墨暗夜深色模式 · 星蓝 #6C7BEF · 暖黄 #F0C464夜间、暗光环境

1两种切换方式

  • 顶栏 调色板按钮：点一下弹出方案列表，选中即生效，Esc 或点空白处收起。
  • 设置中心 → 外观主题：5 张带缩略预览的卡片，选中项有勾选与描边，便于对比后再决定。

2生效范围

  • 切换是即时的：侧栏、卡片、按钮、进度条、标签、图表、弹窗同步变色，不需要刷新。
  • 浮窗卡片与主窗口共用同一份设置，浮窗会一起换色。
  • 选择会写入本机存储，下次启动直接沿用；首帧前就套用，不会先闪一下默认配色。
  • 内置手册也会跟着当前主题调整配色。
配色只影响观感，不影响数据。换主题后任务、时间块、专注记录、复盘内容全部原样保留。

每日使用流程

早5 分钟做规划

  • 清空闪念：新条目要么转任务，要么直接删掉。
  • 在任务里确认今天最重要的 3 件事（★ 标记），其余任务按四象限排队。
  • 为 3 件要事各安排一个时间块，尤其是「重要不紧急」的那件——它最容易被挤掉。

日间按块执行

  • 进入某个时间块时，打开专注计时，输入这一轮要做什么，选好时长后开始。
  • 把浮窗开起来，倒计时和进行中的任务会一直贴在屏幕边上。
  • 块结束后回到时间块页面，点状态标签切成「已完成」。
  • 临时冒出来的事，不要打断当前专注，先丢进闪念。

晚10 分钟复盘

  • 写今日复盘四问，顺手把有价值的内容沉淀到经验素材库。
  • 看周报页面确认这周的专注时长和成果数量。
  • 勾掉今天完成的习惯打卡，给项目进度条拖一下。
每天只做三件真正重要的事，一年就是一千件。

01 首页驾驶舱

驾驶舱不做录入，只做聚合展示：把各模块当天数据汇总到一屏，让你一眼看清「今天进展如何」。

区块说明
今日完成度按已完成任务数 / 任务总数计算，顶部横幅与右上角胶囊同步显示。
任务统计四格今日任务、已完成、进行中、待完成。
今天最重要的 3 件事显示带 ★ 且未完成的任务，点左侧圆圈可直接完成；没有则提示去任务页添加。
四象限 · 任务分布四个象限各有多少未完成任务，点击任意格跳到四象限视图。
今日时间块安排按时间顺序列出全部时间块与状态，颜色点对应当前进度。
今日专注统计专注块数、累计时长、目标达成率；右上「开始专注」直达计时器。
今日提醒根据闪念积压、逾期任务、专注进度自动生成的提示，无需手工维护。
底部四卡项目进度、习惯打卡（可直接勾选）、今日工作成果、今日复盘入口。

02 闪念

闪念是「只进不出」的缓冲区，唯一目的是让你在专注时不被杂念打断。

  1. 在输入框写下任意想法，按 Enter 或点「捕捉」。
  2. 处理阶段逐条决定：点 转任务（自动落入「重要不紧急」象限，可在任务页再调整），或点垃圾桶删除。
闪念的目标是当天清零。积压超过 10 条，说明需要一次集中整理（建议每天固定在早上或下班前）。

03 任务管理

任务管理分为「列表」和「四象限」两个视图，右上角新建任务。

1新建任务

填写标题、四象限、时间（可选），可勾选「标记为今日最重要的 3 件事」。保存后任务出现在列表顶部。

2状态流转

点击任务左侧圆圈，状态按 待开始 → 进行中 → 已完成 → 待开始 循环切换。切到已完成时进度自动变 100%，切回待开始归 0%。

3筛选与删除

顶部标签页可按全部 / 待开始 / 进行中 / 已完成筛选，右侧显示当前数量。每行末尾的垃圾桶图标直接删除任务（不可恢复，谨慎点击）。

4编辑任务

任务列表不再放独立「编辑」按钮，改成更直接的方式：

  • 单击左侧状态圆点：直接打开编辑弹窗（圆点本身不再是切换状态的开关）。
  • 双击任务名称：也可打开编辑弹窗。
  • 右键任务行：弹出快捷菜单，包含编辑、标记为已完成 / 进行中、复制、删除。

状态切换（待开始 → 进行中 → 已完成）在编辑弹窗内完成，或用右键菜单的「标记为…」一步到位。删除依旧在编辑弹窗底部或右键菜单中操作，均有二次确认。

任务保存后不是「一次性」的：单击任务左侧的状态圆点、双击任务名称，或在四象限视图里双击任务，都能打开编辑弹窗；右键任务行还有「标记为已完成 / 进行中」「复制」「删除」等快捷操作。

  • 可改内容：标题、备注、四象限、状态、时间、进度（0–100% 滑杆）、是否标为今日要事。
  • 备注：写验收标准、上下文或链接，不占列表视觉空间，只在该弹窗内查看。
  • 状态与进度联动：状态改成「已完成」进度自动 100%，改成「待开始」归 0，进行中保留原进度。
  • 删除：弹窗左下角，删除前会二次确认。
需要批量整理时，用「四象限」视图：点标题改优先级与时间，比在长列表里找更直观。

04 四象限视图

按「重要 × 紧急」把未完成任务分到四格，点击左侧导航「优先级 / 四象限」或任务页顶部标签进入。

象限含义与建议
重要且紧急立即做。这类任务应当尽量少，长期偏多说明在救火。
重要不紧急计划做。真正产生长期价值的区域，务必用时间块锁住。
不重要但紧急委托或压缩处理，别让它吃掉大块时间。
不重要不紧急尽量少做，可直接删除。
每格右上角显示该象限未完成任务数。若「重要不紧急」长期是 0，而「重要且紧急」爆满，就该重新规划日程了。

05 日程 / 时间块

时间块是把「计划」落到具体时段的工具。顶部四格统计时间块总数、规划时长、已完成数、实际专注时长。

  1. 点「新增时间块」，填写安排内容、开始与结束时间，选一个图标（太阳=晨间、大脑=深度工作、靶心=目标推进、咖啡=休息、人群=会议、发送=交付、循环=复盘）。
  2. 列表按开始时间自动排序。
  3. 执行完一段，点右侧状态标签循环切换 待开始 → 进行中 → 已完成。
建议每天只安排 4–6 个时间块，并留出 20% 空白。排满的日程经不起任何意外，反而全部崩掉。

06 专注计时

番茄钟式计时器，四档预设：25 / 45 / 60 / 90 分钟。

  1. 在输入框写下「这一轮专注做什么」，方便事后回顾专注去向。
  2. 选择预设时长，点「开始专注」。
  3. 中途需要中断可点「暂停」，回来继续；点「重置」回到完整时长且不记录。
  4. 提前完成点「完成」，按实际已过分钟记录（最少 1 分钟）；正常倒计时结束则记录完整时长。

右侧「今日专注概览」显示专注块数、累计时长与目标达成率，可直接切换 2 / 3 / 4 / 6 小时目标；下方「今日专注记录」列出每一轮的时长与主题。

计时基于页面运行，关闭应用会中断当前一轮。建议不要在专注中途退出程序。

07 项目管理

管理跨天、跨周的中长期事项。新建时填写名称、简介、计划开始 / 截止日期与颜色标识。

  • 列表视图：每张卡片显示状态（进行中 / 已暂停 / 已完成）、计划周期条（起止日期 + 今天位置）、节点进度与「最后跟进 · N 天前」；已逾期 / 停滞 7 天以上会亮红黄标签，顶部统计同步给出「需要关注」数量。
  • 点卡片进入详情：进度概览（手动拖动，或由节点按权重自动计算）、计划时间线、节点里程碑、跟进记录、关联任务五个区块，左上角箭头返回列表。
  • 节点里程碑：加入第一个节点后进度自动切换为「按节点计算」，也可随时改回手动；勾选节点即更新进度，全部完成自动记为已完成。每个节点可设截止日期，逾期会标红。
  • 跟进 / 汇报记录：按「进展汇报 / 风险阻塞 / 计划变更」三类记录，形成倒序时间流，用于持续跟进与对外汇报；记录时可同步更新进度（手动模式下）。
  • 周报页「项目跟进」区块自动汇总本期项目进展与风险，点「复制本期汇报」一键拿到可直接发出去的汇报文案。
  • 任务编辑里选「归属项目」即可把任务挂到项目，详情页「关联任务」自动归集并显示状态。

08 目标管理

按分类（事业 / 学习 / 健康 / 财务 / 生活）管理可量化目标，新建时设定目标值、单位与截止日期。

  • 点 + / − 按目标值的 5% 为步进调整当前进展（至少 1 个单位），完成度自动换算成进度条。
  • 目标值达到即 100%，超出的部分不再累加。
  • 目标与任务不同：任务是「做什么」，目标是「往哪去」。

09 习惯打卡

管理每天 / 每周重复的小事。新增时填名称、选频率。

  • 点击左侧方块打卡，再点一次取消。当天即可在驾驶舱勾选。
  • 每行右侧 7 个色块代表最近 7 天，绿色为已打卡。
  • 「连续天数」会自动计算：今天未打卡时从昨天起算，因此不会被误判为断签。
  • 顶部统计习惯总数、今日已打卡、最长连续天数、今日完成率。
一次只新增 1–2 个习惯。同时上十个，通常十个都坚持不下来。

10 知识素材库

存放外部获取的、可复用的资料与要点。

  • 点「收录素材」，填标题、内容、标签（逗号分隔，支持中文逗号与空格）。
  • 搜索框实时匹配标题、内容与标签；标签栏可点选筛选，再点一次取消。
  • 卡片右下角标签可辅助归类的可视化，删除在卡片右上角。

11 经验素材库

存放自己总结的教训与方法，来源通常是复盘。与知识库的区别：知识来自外部，经验来自自己。

  • 点「记录经验」，填标题、具体经验、标签。
  • 建议以「场景 + 做法」的形式写，例如「需求不清晰时，先做可点原型再对齐」。

12 工作成果

记录看得见的产出，用于月报、述职或自我激励。

  • 点「记录成果」（或新增），填写标题、补充说明、类型与日期。
  • 列表按时间倒序展示；周报 / 月报中的「成果记录」实时统计数量。

13 周报 / 月报

周期统计页，顶部切换 本周 / 本月 / 近 7 天 / 近 30 天，右侧显示该区间的起止日期。

区块含义
四格统计区间内专注时长、专注次数、复盘篇数、成果记录数。
每日专注分布柱状图，柱高对应当天专注分钟数，无记录为浅灰空柱。
周期小结有专注记录的天数、平均单日专注、任务完成率、习惯今日完成。
复盘摘录区间内最近 5 篇复盘的最大成果摘要。
每周固定看一次「有专注记录的天数」，它比总时长更能反映节奏稳不稳。

14 时间复盘

每天四个问题，写完点「保存复盘」，内容存入本地并出现在历史列表中。

  1. 今天完成了什么？——对照早上的 3 件要事看命中率。
  2. 最大的成果 / 收获是什么？——哪怕很小也记下来。
  3. 时间主要花在哪了？有什么可以优化？——结合专注记录，诚实面对分心。
  4. 明天最重要的 3 件事？——现在定好，明早直接开干。

同一天可以多次编辑，保存会覆盖当天内容；历史复盘按日期倒序列在右侧。周报会读取这些内容作为摘录。

15 设置中心

  • 个人资料：昵称（显示为右上角头像首字母）与个人宣言（显示在驾驶舱横幅），改完点保存。
  • 专注目标：每日专注时长目标，可选 2 / 3 / 4 / 6 / 8 小时，影响达成率与专注页进度。
  • 数据管理：导出数据备份（JSON 文件）、导入数据、重置全部数据。
  • 关于：查看版本与运行方式。

浮窗卡片与贴边收起

浮窗解决一个具体问题：干活时不想一直盯着主窗口，又不想忘记手上这件事。点顶栏的「浮窗」按钮开启。

1两种形态

  • 桌面浮窗（Windows 安装版）：独立无边框窗口，始终置顶、不占任务栏，可拖到屏幕任意角落；主窗口最小化后它依然可见。
  • 应用内浮层（浏览器 / 网页预览）：贴在主窗口右下角的卡片，可用顶部标题栏拖动位置。

2卡片里能做什么

  • 看到专注倒计时与当前专注主题，随时开始或暂停。
  • 列出「进行中」任务与今日要事，点左侧方框直接完成。
  • 点任务右侧的计时图标，立刻以该任务开启一轮专注。

3贴边收起

点卡片右上角的图钉，浮窗会缩成屏幕右边缘的一条窄签，只显示倒计时和任务数；点窄签随时展开。桌面浮窗收起时窗口本身会缩成一个小方块贴在右侧，不遮挡内容。

浮窗与主窗口共用同一份本地数据：在浮窗勾任务、开计时，主窗口立即同步，反之亦然，无需刷新页面。

方法论：四步闭环

工具只是外壳，真正起作用的是循环。建议按下面四步走，一周后再调参数。

1捕捉 — 降低记录成本

任何念头先丢进闪念，不判断、不分类。判断留到专门的处理时间，避免在专注中途切碎注意力。

2排程 — 给重要的事留位置

先选 3 件要事，再排时间块，而不是把任务填满全天。四象限里的「重要不紧急」必须占住一整块时间，否则永远排不上。

3专注 — 一次只做一件事

一个时间块只对应一个明确产出。计时器的作用不是计时，而是让你无法同时开三件事。

4复盘 — 把经验变成资产

每天 10 分钟记录，每周看一次报表。复盘的关键是找出「明天要改的一件事」，不是写检讨。

计划不是保证不被打断，而是被打断后知道该回到哪。

数据存储与备份

应用完全离线运行，所有数据保存在本机 WebView 的本地存储（localStorage）中，不联网、不上传、无账号。

  • 备份：设置中心 → 导出数据备份，生成 dayweave-backup-日期.json。
  • 恢复 / 换机：设置中心 → 导入数据，选择之前导出的 JSON 文件，导入后立即生效。
  • 重置：设置中心 → 重置全部数据，恢复为演示数据（不可撤销，建议先导出）。
卸载应用、清理系统缓存或重置浏览器组件，都可能清除本地数据。养成每月导出一次备份的习惯；重要节点（例如年终复盘前）单独导出一份。

常见问题

安装时产品名显示为 DayWeave，正常吗？

正常。Windows 安装包（WiX）不支持中文产品名，因此安装程序内部标识使用英文 DayWeave；应用窗口标题和界面以中文名「织日」为主，不影响使用。

启动时提示缺少 WebView2 运行时怎么办？

安装微软官方的 Microsoft Edge WebView2 Runtime 即可，装一次长期有效。Win10 / 11 绝大多数系统已内置。

数据会丢吗？换了电脑怎么迁移？

数据只在本机，卸载或清理缓存可能丢失。迁移方式：旧机导出 JSON → 新机安装应用 → 导入 JSON。

专注计时关掉窗口会怎样？

切换页面、开关浮窗都不会中断计时——计时器挂在应用全局。关闭整个应用会停止计时；重新打开时若倒计时已过，会自动补记一条专注记录。

浮窗点不出来或看不见？

先确认顶栏「浮窗」按钮已点击；桌面浮窗默认置顶且不占任务栏，若被其他置顶软件（如投屏、会议）遮住，从任务栏关闭那个软件即可。浮窗被拖到屏幕外时，关掉浮窗重新打开会回到默认位置。

浮窗和主窗口的数据是同一份吗？

是。两个窗口共用本机同一份本地存储，改动实时双向同步，不需要刷新。

演示数据怎么清空？

设置中心 → 重置全部数据。注意重置会同时清掉你自己录入的内容，请先导出备份。

为什么「今日完成度」和任务页数量不一致？

完成度按全部任务计算（含非今日任务），是全局快照；任务页的筛选标签只统计当前筛选结果。

任务进度百分比能手动改吗？

能。单击任务左侧的状态圆点（或双击任务名称）打开编辑弹窗，里面有 0–100% 的进度滑杆；状态切到「已完成」时进度自动补满，切到「待开始」自动归零。项目进度则可以直接在卡片上拖动进度条。
