# 端到端回归测试（tests/e2e.cjs）

零依赖：只用 Node 内置模块 + 本机 Chrome 的 CDP 协议驱动页面，不需要 playwright。

## 跑法

```bash
# 1. 先起服务（二选一）
pnpm build && pnpm preview --port 4173 --strictPort
pnpm dev                      # 开发服务器，端口 1420

# 2. 再跑测试
pnpm test:e2e                 # 完整 25 套件，连续 2 轮
pnpm test:e2e:quick           # 只跑 1 轮
node tests/e2e.cjs --rounds=5 # 自定义轮次
node tests/e2e.cjs --only=浮窗  # 只跑名字含「浮窗」的套件

# 换目标地址
TM_URL=http://localhost:1420/ node tests/e2e.cjs --rounds=1
```

退出码 0 = 全部通过；结果同时写入 `tests/last-report.json`。

## 约定

- 每个套件开始前清空 localStorage 并刷新，保证从种子数据出发，互不干扰。
- 每轮用独立的 Chrome profile（放在系统临时目录，结束自动删除），不会污染项目目录。
- 页面运行时异常（`Runtime.exceptionThrown` / `console.error`）会被单独计入失败，即使断言全过也算不通过。
